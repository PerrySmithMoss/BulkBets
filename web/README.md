# BulkBets

Welcome to BulkBets, where the worlds of bodybuilding and betting collide! Experience the excitement of predicting bodybuilding show outcomes and placing bets on your favourite athletes. With real-time updates, expert insights, and thrilling competitions, BulkBets is the ultimate destination for fitness enthusiasts and betting aficionados alike. Join us now and elevate your bodybuilding experience with every wager!

For local configuration, copy `.env.example` to `.env` in this directory. The only
app-specific variable is `API_URL`, which defaults in the example to
`http://127.0.0.1:8080`. Next.js loads `.env` automatically. Restart the dev server
after changing it. Browser API calls use the same-origin `/api` proxy, so no
`NEXT_PUBLIC_*` variables are needed. Local `.env*` files are ignored by Git;
`.env.example` is the shareable template.

See the [repository setup guide](../README.md) for service startup and test commands.
